# Pesquisa

Levantamento de apoios existentes nos Açores (out. 2026). É a primeira fonte de conteúdo
do site.

Não é conteúdo publicado. Cada Apoio criado a partir daqui começa em **rascunho** e só é
publicado depois de ter pelo menos uma Fonte oficial (diploma, edital ou página oficial)
e uma Verificação por um Colaborador.
